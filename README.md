## 这套“三网”里，联通走的不是 9929

这是本文最该记住的一段。

AkkoCloud 圣何塞系列对外标的是 CN2 GIA 优化线路，早期介绍里也写作“三网回程 CN2 GIA”。第三方在圣何塞机器上做的回程测试给出的结果是：电信回程走 CN2 GIA，移动回程走 CMIN2，联通回程从 CN2 GIA 骨干落地后再转入联通 AS4837 网络。

也就是说，它的实际组合是“电信 GIA + 移动 CMIN2 + 联通借道 GIA”，和“电信 GIA + 联通 9929 + 移动 CMIN2”那种严格分线不是一回事。

这个差别在什么情况下会咬到你？如果你的访客、你自己常用的宽带以联通为主，那么你访问这台机器时走的是电信的精品网。CN2 GIA 本身质量没问题，但它承载的是电信方向的流量，联通方向的拥塞控制在电信那条链路上，你买不到联通 9929 那种“联通人走联通精品网”的原生优势。反过来，如果你的访客以电信和移动为主，这套组合是对得上的。
